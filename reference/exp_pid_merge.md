# Old name for [`pid_merge()`](https://dcr-eyethink.github.io/eyethinkdata/reference/pid_merge.md)

Please use
[`pid_merge()`](https://dcr-eyethink.github.io/eyethinkdata/reference/pid_merge.md)
instead.

## Usage

``` r
exp_pid_merge(..., link = "pid")
```

## Arguments

- ...:

  Data tables to merge.

- link:

  The column(s) to match on.

## Value

See
[`pid_merge()`](https://dcr-eyethink.github.io/eyethinkdata/reference/pid_merge.md).
